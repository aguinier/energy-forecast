# Energy Forecasting Module Dependencies
#
# ============================================================================
# THESE PINS ARE EXACT ON PURPOSE (ABL-597)
# ============================================================================
# Every serving artifact is a `models/<CC>/<type>/model.joblib` pickled by one
# specific library build and loaded by whatever the container resolved at its
# last rebuild. `models/` is gitignored, so no commit protects those bytes: a
# `>=` floor lets an unrelated rebuild float the library under them and either
# break the load or -- worse -- change predictions without breaking anything.
#
# The versions below are what the live `energy-forecast` container was running
# on 2026-08-28 (`docker exec energy-forecast python3 -m pip freeze`, captured
# under ABL-598), NOT what resolves fresh today. This is a freeze at a known-good
# state, not a bump. Do not "fix" an unsatisfiable pin by moving a version --
# report it instead.
#
# Which packages need an exact pin was determined, not guessed: a pickletools
# opcode replay over all 67 top-level artifacts resolved every GLOBAL /
# STACK_GLOBAL to a (module, qualname) pair. Counts below are artifacts naming
# that module in their own bytes; re-derive them with
# `scripts/abl597_artifact_load_path.py` rather than trusting them here.
# Full pack: reports/abl_597_artifact_load_path.md
#
# Raising any pin here means re-reading the artifacts under the new version
# first -- `base_score` is the witness that catches a silent level reset.
